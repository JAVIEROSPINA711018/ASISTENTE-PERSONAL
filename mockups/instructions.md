# Instructions for Generating Visual Mockups

## Overview
This directory contains instructions for generating visual mockups of the Cerebro Personal application using Apple's design language.

## Prerequisites
To generate the mockups, you'll need access to one of these tools:
- DALL-E (https://openai.com/dall-e/)
- Midjourney (https://www.midjourney.com/)
- Stable Diffusion (https://stablediffusionweb.com/)
- Or design software like Figma, Sketch, or Adobe XD

## Process

1. **Navigate to the design-mockups directory**
   ```
   cd /Users/javierospina/.gemini/antigravity/scratch/cerebro-personal/design-mockups/
   ```

2. **For each view, use the corresponding prompt file:**
   - Dashboard: `dashboard-mockup-prompt.txt`
   - Authentication: `auth-mockup-prompt.txt`
   - Email: `email-mockup-prompt.txt`
   - Finance: `finance-mockup-prompt.txt`
   - Tasks: `tasks-mockup-prompt.txt`

3. **Copy the content of each prompt file**

4. **Paste the content into your chosen image generation tool**

5. **Generate the image and save it to the mockups directory**

## Example Process with DALL-E

1. Go to https://openai.com/dall-e/
2. Sign in to your account
3. Open the dashboard-mockup-prompt.txt file
4. Copy the entire content
5. Paste it into the DALL-E prompt input
6. Click "Generate"
7. Save the resulting image as "dashboard-mockup.png" in the mockups directory

## Image Naming Convention
- dashboard-mockup.png
- auth-mockup.png
- email-mockup.png
- finance-mockup.png
- tasks-mockup.png

## Review Process
Once all mockups are generated:
1. Review each mockup for accuracy
2. Provide feedback on any elements that need adjustment
3. Request revisions as needed
4. Approve final versions before implementation begins

## Design Principles to Verify
Ensure each mockup reflects:
- Clean, minimalist aesthetic
- Apple's SF Pro font family
- Consistent spacing and padding
- Appropriate use of the blue accent color
- Rounded corners and subtle shadows
- Clear visual hierarchy
- Accessibility considerations
