# Cerebro Personal - Apple Design Mockups

This directory contains prompts for creating visual mockups of the Cerebro Personal application using Apple's design language.

## Files Included

1. `apple-design-research.md` - Research on Apple's design principles
2. `dashboard-mockup-prompt.txt` - Prompt for dashboard view mockup
3. `auth-mockup-prompt.txt` - Prompt for authentication screen mockup
4. `email-mockup-prompt.txt` - Prompt for email view mockup
5. `finance-mockup-prompt.txt` - Prompt for finance view mockup
6. `tasks-mockup-prompt.txt` - Prompt for tasks view mockup

## How to Use These Prompts

You can use these prompts with AI image generation tools like:

- DALL-E
- Midjourney
- Stable Diffusion
- Or design tools like Figma, Sketch, or Adobe XD

Each prompt is designed to generate a mockup that follows Apple's design principles while adapting them to the specific needs of the Cerebro Personal application.

## Design Principles Applied

- Simplicity and clarity
- Consistent typography (SF Pro font family)
- Appropriate use of white space
- Clear visual hierarchy
- Accessibility considerations
- Responsive design elements
- Familiar interaction patterns

## Next Steps

To see actual visual mockups:

1. Copy the content of any prompt file
